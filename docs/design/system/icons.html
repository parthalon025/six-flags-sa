SF Symbols are Apple's, and not licensed for the web — so these are drawn to match rather than imported: the same 24-unit box, the same rounded stroke ends, the same optical weight. Names match the symbols they stand in for, so swapping any one of them for the real thing later is a one-line change.

Everything paints in currentColor, which is what lets a button tint its glyph by setting color and nothing else.
