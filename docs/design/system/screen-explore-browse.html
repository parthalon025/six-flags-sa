What a Profile changes here

This shot was taken with a session seeded into parkbound.session, not with a sign-in. There are no Clerk keys on the machine that took it, so the sign-in card and the OAuth buttons are genuinely unreachable and are not drawn anywhere in this twin.

The seeded Profile carries two fields and nothing that pretends to be a person — Seeded Profile and an id that says what it is. Rank, Title and XP were left out so the app derives them with its own functions. If a name, Title or number on this shot looks like a real guest's, it is not; treat every one of them as the app's own default.
