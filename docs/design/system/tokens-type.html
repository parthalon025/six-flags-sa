Display: rounded geometric sans for PARKBOUND, attraction names, big numbers. Interface: highly legible neutral sans for everything else. --display is wired from next/font when available; the stack still works offline on the system fallback.

Apple's built-in text styles at the Large (default) Dynamic Type size, as size / leading / tracking. Sizes and leading come from the HIG specifications table; tracking is joined onto it from the separate SF Pro tracking table by point size.

Note the tracking column changes sign. It tightens to a minimum around 19–20pt, then opens back up above that — the optical-size transition showing up in the metrics — so Large Title and Title 1 track *open*. Reading the curve as "tighter as it gets bigger" gets both of them backwards. A browser applies none of this on its own: -apple-system gets the right glyphs and neutral tracking, so it has to be set by hand.

The rules below are written with literal values rather than these tokens, which is how they arrived; the tokens are here as the reference to check a value against before adding one.
