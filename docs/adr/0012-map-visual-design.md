# Map visual design — souvenir calm, nav forward, Shapes when lines crowd

Park Bound’s drawn **Venue** map optimizes for arm’s-length outdoor reading: printed souvenir-map calm at rest, utility when **Go** is active. **Trail** and **Park Midnight** are the always-on **Palettes** (marketing canon); **Skins** are earned delight that must still pass shape + colour + glyph redundancy.

**At rest:** districts + gates + **Meet** / **Party** if any + next **Plan** stop on first paint; other categories visible but quieter until zoom or filter. **Palette** flips auto from local time / park hours with a manual sun/moon override. **Overlay** draws with **Field research look** (kind-specific geometry + subtle provisional cue). **Fog** on the canvas is **Profile** opt-in — default off so restrooms and **Members** stay findable.

**During Go:** course-up, route and puck promoted, category key folded. Declutter never drops puck, route, **Meet**, **Members**, or the primary **Place** before districts and POI labels. Motion: **Go** chrome and NEED HELP only — no ambient map shimmer; quest celebration stays in sheet/toast.

**When similar lines run close** (parallel paths, stacked coaster track): category reads through marker **Shapes** (disc / chip / diamond / pin) and glyphs at **Places** — not hue alone on the lines. Selected coaster track may still light for ownership.

**Skins:** never required to read the map; never reposition **Places**. Success: grandma comprehension, timed find-a-**Member** / find-a-restroom in dogfood, sunlit screenshot pairs for store.
