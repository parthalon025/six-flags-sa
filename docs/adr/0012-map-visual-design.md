# Map visual design — souvenir calm, nav forward, Shapes when lines crowd

Park Bound’s drawn **Venue** map optimizes for arm’s-length outdoor reading: printed souvenir-map calm at rest, utility when **Go** is active. **Trail** and **Park Midnight** are the always-on **Palettes** (marketing canon); **Skins** are earned delight that must still pass shape + colour + glyph redundancy.

**At rest:** districts + gates + **Meet** / **Party** if any + next **Plan** stop on first paint; other categories visible but quieter until zoom or filter. All present category markers on at gate entry; labels stay quiet until zoom — next **Plan** **Place** gets declutter promotion. **Palette** flips auto from local time / park hours with a manual sun/moon override. **Overlay** draws with **Field research look** (kind-specific geometry + subtle provisional cue). **Fog** on the canvas is **Profile** opt-in — default off so restrooms and **Members** stay findable. Device-less **Members** (kids) on the roster → sparser first paint; no separate kids renderer — optional `junior` **Skin** is delight, not a second map mode.

**Land tints:** souvenir strength on **Trail** / **Park Midnight**; earned **Skins** may go louder.

**Height filter:** marker verdict only (Signal Red barred, **Companion** plus) — **Shapes** stay so category reads; no hiding whole categories; list/sheet carries detail.

**During Go:** course-up, route and puck promoted, category key folded. Declutter never drops puck, route, **Meet**, **Members**, or the primary **Place** before districts and POI labels. Motion: **Go** chrome and NEED HELP only — no ambient map shimmer; quest celebration stays in sheet/toast.

**When similar lines run close** (parallel paths, stacked coaster track): category reads through marker **Shapes** (disc / chip / diamond / pin) and glyphs at **Places** — not hue alone on the lines. Overview zoom keeps line spaghetti quiet; selection lights the owner track. Parallel offset only if dogfood still fails after that.

**Skins:** never required to read the map; never reposition **Places**. First polish ship: Postcard, Marquee, Junior, Pixel tycoon (plus always-on **Palettes**). Store: **Trail** party-day frame for comprehension; **Park Midnight** / delight **Skin** for screenshot bait.

Success: grandma comprehension, timed find-a-**Member** / find-a-restroom in dogfood, sunlit screenshot pairs for store.
