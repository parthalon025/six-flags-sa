# Family facts on the party mesh

A **Party** is a family product: **Member** records carry height, **With adult**, battery/charging, and an in-bounds **Location** trail (last-known stays when live updates stop outside **Venue** bounds). Device-less **Members** (kids without phones) are full roster seats and are not evicted for silence. There is no location pause. These fields are party-scoped, not **Contributions**.

Canonical language: root `CONTEXT.md`.
