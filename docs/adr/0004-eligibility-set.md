# Eligibility set is this phone’s tagged clump

Map / list / glance **Eligibility** uses one people set: matching **Subgroup** tags on this phone (including device-less **Members**), or the whole **Party** if this phone is untagged. Untagged device-less **Members** do not shadow a tagged phone — tag kids when you split so the limiter is honest, not a ghost from Mom’s half. Device-holding **Members** are the app’s decision makers: they tag, set height / **With adult**, and may remove a device-less seat (home with Grandma is a roster remove, not a **Meet** leave). Phoneless people are limiters on those phones, not users. Unset **With adult** means accompanied; leaving someone at the **Meet** is a **Subgroup** change, not an “alone” switch — an unattended device-less rider is out of scope. Stale **Managed Guest** height prompts at seed; skip keeps last inches.
