# Plan is one shared list

There is one **Plan**: the **Party**’s ordered **Places**. A pre-party draft on this phone is that same **Plan**, not a Scenario or a second store. Create, join, or resume promotes the draft only when the shared **Plan** is empty, then clears it — so leave cannot resurrect a competing list. `set-plan` is last write on the **Host**. Per-**Member** favorites are not this list. Meet/target command dumps are not **Plan**.

Canonical language: root `CONTEXT.md`.
