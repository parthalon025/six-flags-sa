# Agent skills

Matt Pocock skills are **global** (`~/.agents/skills`), not vendored here.

Do not add a `skills/` tree or `skills-lock.json` in this repo. `npm run skills:check` asserts that. Install or upgrade with `node scripts/install-global-skills.mjs`.

GitNexus skills for this project live under `.claude/skills/gitnexus/`.

See `docs/agents/skills-lock.md`.
